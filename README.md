# 김도현 | AI Product Builder

AI 기반 웹 서비스와 생산성 도구를 기획하고, 제품 수준의 기능으로 구현하고 있습니다.
주요 관심사는 AI 에이전트, Next.js/FastAPI 서비스, 데이터 기반 추천, SaaS 운영 자동화입니다.

## Featured projects

- [WebPilot AI](https://github.com/ghimdohyun/webpilot-ai) — Claude 기반 브랜드 진단·경쟁사 분석·홈페이지 기획 도구. FastAPI backend와 Next.js frontend를 하나의 저장소로 통합했습니다.
- [imweb AI Toolkit](https://github.com/ghimdohyun/imweb-ai-toolkit) — 아임웹 제작 업무를 위한 AI surface, skill, plugin toolkit.
- [DreamHelixion Web Builder](https://github.com/ghimdohyun/dreamhelixion-web-builder) — AI 홈페이지 빌더, 프로젝트 관리, 게시·도메인·결제 흐름을 포함한 SaaS.
- [DreamHelixion Planner](https://github.com/ghimdohyun/dreamhelixion-planner) — 대학 교육과정·졸업요건 분석과 맞춤형 학습계획 추천 서비스.
- [Investment AI Assistant](https://github.com/ghimdohyun/investment-ai-assistant) — Claude AI 기반 데일리 투자 브리핑 및 Telegram 전달 자동화.
- [Startup Alert](https://github.com/ghimdohyun/startup-alert) — 스타트업·투자 관련 정보를 수집하고 알림으로 전달하는 서비스.
- [Fieldlink Facility SaaS](https://github.com/ghimdohyun/fieldlink-facility-saas) — 시설 운영·현장 업무를 위한 SaaS MVP.
